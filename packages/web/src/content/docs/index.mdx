## What is EchoAI?

EchoAI is a terminal-first coding agent that helps developers inspect repositories, edit files, run checks, and resume work across local and hosted sessions. The first market release focuses on hosted EchoAI routing, DeepSeek/Kimi presets, strict permissions, and usage visibility.

## Quick Start

```bash
# Install EchoAI
npm install -g echoai

# Start your first chat
echoai chat

# Initialize project instructions
echoai init

# Use a hosted preset
echoai "Review this code for security issues" --provider echoai --model code
```

## Core Features

### 🤖 Intelligent Code Assistance
- **Code Generation**: Write functions, classes, and entire modules with AI assistance
- **Bug Detection**: Identify and fix issues in your codebase automatically  
- **Code Review**: Get AI-powered code reviews and suggestions for improvements
- **Refactoring**: Modernize and optimize your code with intelligent refactoring suggestions

### 🔧 Powerful CLI Tools
- **Interactive Chat**: Engage in conversations about your code and get contextual help
- **File Operations**: Read, write, and modify files with AI assistance
- **Git Integration**: Commit messages, branch suggestions, and code history analysis
- **Custom Commands**: Create and share custom AI-powered commands for your workflow
